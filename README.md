# Restaurant App

A more realistic restaurant ordering demo built with HTML, CSS, and JavaScript.

## Features

- Menu categories for Starters, Mains, Desserts, and Drinks
- Dish details including ratings, calories, and chef recommendations
- Interactive cart with quantity controls and remove buttons
- Pickup/delivery order selection and special request notes
- Responsive design for desktop and mobile

## Open the app

- Open `index.html` in your browser.
- Or use a local server such as the VS Code Live Server extension.
